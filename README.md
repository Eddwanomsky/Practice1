
У ході виконання лабораторно-практичної роботи було опановано роботу з консольним клієнтом Git у двох частинах, виконано практичні вправи та зафіксовано кожен крок за допомогою скріншотів, які розміщені у папці screenshots/ даного репозиторію. Під час проходження першої частини,я опанував базові операції: конфігурація та ініціалізація локального репозиторію. Після цього,мав практику з додавання файлів до коміту та перегляду минулих версій файлів (за необхідністю - відкат коміту),але в подальшому,я створював окремі гілки для комітів,щоб було більш зручно для контролю версії проєкту.У першій частині було створено HTML файл та файл стилів до нього,більша частина комітів йшла на оновлення HTML файлу.
Після завершення першої частини,я почав проходити другу, там я навчився злиттю гілок та вирішенню проблем з процедурою злиття.Окрім цих навичок, у другій частини,я навчився створювати теги до версій проєкту.

Інтерактивний формат "Git How To" дозволяє краще зрозуміти внутрішню логіку роботи Git (як створюються зліпки стану, як працюють вказівники гілок та HEAD).Особливо корисною виявилася практика вирішення конфліктів злиття та робота з командую git reset / git revert, оскільки ці операції часто викликали в мене труднощі та нерозуміння.Набуті мною навички були гарним фундаментом для подальшої розробки програмного забезпечення та ведення власних проєктів на GitHub.
